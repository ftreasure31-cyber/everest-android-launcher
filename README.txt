EVEREST - install on your phone

1. Upload every file in this folder to a free HTTPS host (Netlify Drop, GitHub Pages or Cloudflare Pages). Keep index.html at the top level.
2. Open the address in Chrome on your phone.
3. Chrome menu (three dots) > Install app (or Add to Home screen). EVEREST appears with the rocket E icon and opens full screen.
4. For a real .apk file: go to pwabuilder.com, enter your address, choose Package for stores > Android, download, then open the APK on your phone (allow Install unknown apps for your file manager when asked).
